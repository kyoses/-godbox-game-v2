# godbox-game 上帝模拟器

低多边形风格的 2D 沙盒上帝模拟游戏（参考 WorldBox 世界盒子）。原生 Kotlin + Android Canvas 实现。

## 功能

- 80x80 随机地形生成（草/水/山/沙/树）
- 4 种生物：人、羊、狼、鱼，各有 AI（饥饿/战斗/繁殖/随机游走）
- 文明系统：当 ≥5 个邻接人类聚集时自动形成部落、扩张村庄
- 战争：不同部落相遇时互相敌对
- 天气：晴/雨/雷 + 雨滴粒子
- 5 种灾害：陨石/洪水/火山/神圣之光/闪电
- 上帝之手：长按单格进入放大视角
- 工具栏：地形/生物/灾害选择 + 暂停 + 清除

## 编译

用 Android Studio 打开 `godbox-game/`，Sync Project 后 Build APK。
或通过 GitHub Actions（已配置）自动构建。

## 操作

- **单指拖动**：相机平移
- **双指缩放**：缩放 0.5x–3x
- **单击**：放置当前工具（地形/生物/灾害）
- **长按**：进入上帝之手（放大该格）
- **双击**：退出上帝之手
- 工具栏切换工具
- 暂停/清除按钮

# 三国做皇帝 · 策略模拟手游 · 设计提示词

下面给你一份可直接喂给美术/策划/AI生成工具的**完整游戏设计提示词**，重点突出"自由度极高、皇帝可做一切事"。

---

## 一、项目核心定位（Concept）

**类型**：三国题材 · 高度自由 · 皇帝视角 · 策略 + 模拟 + 轻度RPG · 单机手游（Android APK）
**核心卖点**：玩家不是扮演某一个将领或某一个城池的诸侯，而是**从登基到驾崩全程扮演皇帝**——上朝理政、御驾亲征、选妃立储、巡游微服、与三国群雄合纵连横，所有"皇帝能做的事"都可执行，玩法之间高度联动。

---

## 二、世界观与剧本（World & Scenario）

- **时代**：东汉末年（184年黄巾之乱 → 280年晋统一，玩家可选择剧本起点）
- **可选剧本起点**：
  1. **何进剧本**：开局已是外戚大将军，面临十常侍乱政
  2. **董卓剧本**：开局已是相国，挟天子以令诸侯
  3. **曹操剧本**：开局已是魏王，曹丕可直接登基
  4. **刘备剧本**：开局已是蜀汉昭烈帝
  5. **孙权剧本**：开局已是吴大帝
  6. **白袍剧本**：自定义势力，从一介白衣起兵，统一天下后称帝
- **结局分支**：统一称霸、禅让内禅、被篡、被刺、暴毙、修仙隐退等 ≥30种结局

## 三、核心系统（Core Systems）—— 高度自由

### 1. 皇帝日程系统 ⏰
每日分 **卯、辰、巳、午、未、申、酉、戌、亥** 九个时辰，每时辰1次行动：
- **早朝**：批阅奏折（税收/军情/人事/刑狱/工程/外交6类）
- **召见**：单独面见任意臣子，触发剧情/任务
- **微服出巡**：匿名出宫，触发随机事件
- **御书房**：研读兵法/提升属性
- **后宫**：翻牌/侍寝/立后/废后
- **校场**：观军/亲征
- **祭祀/封禅/南巡/北狩**：触发大型国运事件

### 2. 帝王六维属性 👑
| 属性 | 影响 |
|---|---|
| 武力 | 单挑、亲征伤害 |
| 智略 | 计策成功率、内政效率 |
| 统御 | 军团规模、士气 |
| 仁德 | 民忠、招降概率 |
| 威严 | 臣忠诚度、御下强度 |
| 魅力 | 外交、招贤、后宫 |

可随剧情升级或通过"丹药/奇遇/名师"突破。

### 3. 朝政与奏折 📜
- 奏折**不是QTE**，而是真实提案：玩家可**批红/留中/驳回/交议/转交**任意臣子
- 玩家可**绕过正常流程**直接口谕（增加皇权威严但易引发反弹）
- 支持**自定义政令**：玩家可起草新政策，如"摊丁入亩""科举改制""盐铁专营"——影响数值由AI引擎动态结算

### 4. 军事系统 ⚔️
- **兵种**：步兵/骑兵/弓兵/水军/攻城器械/虎豹骑/白毦兵/连弩兵（三国特色）
- **阵法**：八阵图/鸳鸯阵/锋矢阵/偃月阵——可自由布阵（5×5或8×8格子）
- **武将**：每个武将独立AI，可下达"自由作战/坚守/偷袭/围城/劝降"等指令
- **亲征**：皇帝亲自上场，可释放专属技能（如"天子剑·横扫"）
- **水战**：赤壁、夷陵等水战地图真实还原风向/水流

### 5. 外交系统 🤝
- **五维外交**：亲善/中立/敌对/同盟/附庸
- 手段：会盟/联姻/质子/威胁/贿赂/离间/刺杀/假途灭虢
- **舌战群儒式辩论**：与敌国使者实时文字交锋
- **间谍网**：可派细作潜伏对方阵营，长期任务

### 6. 内政系统 🏛️
- **郡县制管理**：每郡每县独立经营，税收/徭役/赈灾可逐县设置
- **六部动态**：吏/户/礼/兵/刑/工，玩家可越权指挥或全权委托
- **建设工程**：水利/驰道/城池/学宫/神庙——需选派臣子监督
- **流民/世家/豪强**：三方势力平衡，玩家政策会引发不同反应

### 7. 后宫与宗室 💞
- **选秀**：每3年一次，可定制容貌/才艺/家世
- **子嗣系统**：皇子有独立属性，参与夺嫡
- **立储与夺嫡**：可立长/立嫡/立贤/立爱/废太子——引发宫廷剧变
- **家宴/赐宴**：提升妃嫔/宗室关系

### 8. 人才与科举 🎓
- **招贤馆**：发布招贤令，全球搜索在野人才
- **科举**：自定义科目（诗赋/策论/武举/算学/律法）
- **任用**：臣子可任任何官职，玩家可强制任命（引发不满）
- **暗杀/流放/赐死**：高自由度人事手段

### 9. 经济与商路 💰
- 货币：铜钱/粮草/铁/盐/马匹五资源
- 商业：丝绸之路/南方丝路/海上贸易
- **玩家可下海经商**：微服身份参与商队

### 10. 奇遇与事件 🎲
- 随机事件池 ≥500条：刺客/祥瑞/天灾/谶纬/异人/仙人
- **可触发修仙线**：左慈/南华老仙/于吉等仙人传授功法

## 四、美术与UI（Art & UI）

**美术风格**：
- 主UI：水墨+工笔重彩，汉代画像砖风格icon
- 立绘：古风写实，头身比1:6.5
- 场景：实景山水+写意宫阙，3D可旋转
- 色调：黑/朱红/鎏金/黛青

**UI布局**：
```
┌─────────────────────────┐
│  永安宫 · 帝历X年X月X日  │  ← 顶栏：时间/位置/快捷入口
├──────┬──────────┬───────┤
│      │          │       │
│ 臣   │  中央    │ 奏折  │
│ 子   │  场景    │ 列表  │
│ 列   │  (3D)    │       │
│ 表   │          │ 待办  │
│      │          │       │
├──────┴──────────┴───────┤
│  [朝会][军事][内政][后宫][外交] │ ← 五大主功能
└─────────────────────────┘
```
